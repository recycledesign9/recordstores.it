# Contributing to RecordStores.it

Thanks for your interest in contributing to **RecordStores.it** 🎶

This project is community-driven and contributions are welcome.

---

## How to Contribute

You can contribute by:

- Reporting bugs
- Suggesting improvements
- Submitting pull requests
- Improving documentation
- Helping with testing and UX feedback

---

## Development Guidelines

- Use clear and readable code
- Keep changes focused and scoped
- Comment critical or complex logic
- Avoid committing credentials or sensitive data
- Follow existing project structure

---

## Pull Requests

When opening a pull request:

1. Describe **what** you changed
2. Explain **why** the change is needed
3. Reference related issues if any

---

## Code of Conduct

Be respectful and constructive.  
This is a collaborative, inclusive project built by music lovers.

Thanks for helping keep independent record stores alive ❤️
